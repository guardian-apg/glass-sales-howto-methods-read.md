# 特注ガラス調達NAVI 事業・Webサイト企画構想

## 1. 事業概要・参入背景
* **強みとポジショニング**: 
  * 業界経験30年の知見と国内外（特に海外）調達網を活用した、特注ガラスの受託調達サービス。
  * 国内町工場の高齢化・廃業による「調達難民」と、大手メーカーの「長納期・小ロット敬遠」の受け皿となる。
  * 素人による海外直輸入（Alibaba等）で頻発する「寸法公差外れ・品質不良」を回避し、国内での厳格な受入検査・公差保証を付加価値として提供。
* **スコープ**: 
  * 海外工場を活用するため「石英ガラス等の修理・再生」は対象外とし、「図面からの新規特注製作」に特化。

## 2. ターゲット顧客と取扱商材
* **先端研究・大学・製薬**: 
  * 特注ホウ珪酸ガラス器具、反応容器、二重管冷却器など（小ロット・試作対応）。
* **半導体・電子部品・光学**: 
  * 高純度石英ガラス治具、石英ボート、ウエハキャリア、サイトグラスなど（高精度・耐熱用途）。

## 3. Webサイト基本設計
* **サイト名**: 『特注ガラス調達NAVI』
  * BtoB調達担当者の検索ワード（特注/ガラス/調達）に合致させ、SEOとポータルサイトとしての信頼性を両立。
* **メインコピー**: 
  * 「図面アップロードで即日対応。30年のプロが目利きする『公差保証付き』海外調達」
* **主要サイト構成（6ページ構成）**:
  1. トップページ（図面アップロード窓口）
  2. 当社が選ばれる3つの理由（最適工場選定／30年の目利き／国内受入検査と公差成績書）
  3. 対応材質・加工精度スペック（石英・ホウ珪酸の公差基準、加工可能サイズ）
  4. 調達・納品フロー（図面UP → 翌日見積 → 海外製造 → 国内受入検査 → 納品）
  5. よくあるご質問（手書き図面対応、NDA締結など）
  6. 運営会社情報

## 4. 図面アップロード＆変換システム要件
* **対応フォーマット**:
  * 2D CAD: `.dxf`, `.dwg`, `.jww`, `.jwc`
  * 3D CAD: `.step`, `.stp`, `.iges`, `.igs`, `.sldprt`
  * 汎用・画像: `.pdf`, `.ai`, `.jpg`, `.png`, 手書きスケッチスキャン
* **システム機能**:
  * ブラウザ即時確認用の2D PDF / 3Dビューア自動生成。
  * 製造工場手配用のDXF / JWW相互変換機能。
* **開発・運用フェーズ（スモールスタート推奨）**:
  * 初期はセキュアなマルチファイル受信フォームを立ち上げ、変換処理は手元のCADソフトで運用検証し、案件増加に合わせてAPI連携（Autodesk Platform Services等）を実装。
